## Очищення даних (Data Cleaning)

Під час очищення даних було виявлено декілька проблем із якістю та структурою даних. Основні проблеми та прийняті рішення наведено нижче.

| Проблема                                     | Рішення                                                                                                                                                                                                             |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Пропуски в датах доставки                    | Пропуски не видаляємо і не заповнюємо, оскільки вони відповідають замовленням, які не були доставлені. Додаємо прапорець `is_delivered`. Показники виручки (`revenue`) розраховуємо лише для доставлених замовлень. |
| Неповні місяці на початку та в кінці періоду | Дані не обрізаємо до повних місяців. Натомість додаємо колонку `in_analysis_period`, яка визначає, чи належить запис до обраного періоду аналізу.                                                                   |
| 610 товарів без категорії                    | Товари не видаляємо. Для них встановлюємо категорію `unknown`.                                                                                                                                                      |
| Категорії товарів португальською мовою       | Додаємо англійську назву категорії за допомогою таблиці перекладів. Якщо переклад відсутній, залишаємо оригінальну португальську назву.                                                                             |
| Кілька відгуків на одне замовлення           | Залишаємо лише останній відгук для кожного замовлення, щоб під час `JOIN` не виникало дублювання рядків.                                                                                                            |
| Дублікати в таблиці `geolocation`            | Зводимо записи до одного рядка для кожного ZIP-коду/ZIP-префікса.                                                                                                                                                   |
| Помилка в назві колонки (`lenght`)           | Перейменовуємо колонку `lenght` на `length`.                                                                                                                                                                        |
| Пропуски в текстах відгуків                  | Не вважаємо це проблемою, оскільки тексти відгуків не використовуються в аналізі. Відповідні текстові колонки не включаємо до очищеного набору даних.                                                               |

### Принципи очищення даних

Основна мета очищення - зберегти якомога більше оригінальної інформації та водночас запобігти дублюванню записів і помилкам під час подальшого аналізу.

Дані видаляються або змінюються лише тоді, коли це необхідно для коректного об'єднання таблиць (`JOIN`), агрегації або розрахунку аналітичних показників.
